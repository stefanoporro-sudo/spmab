Aggiorna le metriche reali del progetto (DataOS):

1. Esegui `npm run metrics` (richiede `.env.local` con le credenziali Supabase — se manca, guida Stefano a crearlo copiando `.env.local.example` e incollando i valori da Vercel → Settings → Environment Variables)
2. Se lo script fallisce per credenziali mancanti o errate, non inventare numeri: fermati e chiedi
3. Una volta generato `.claude/context/metrics.md`, riassumi in 2-3 righe cosa è cambiato rispetto all'ultima volta (se disponibile in `.claude/context/history.md`)
